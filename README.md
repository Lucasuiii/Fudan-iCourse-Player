# Lyue 1.1.1

在已经登录的复旦 iCourse 页面中观看课程。支持课次列表、搜索、自动发现直播源、倍速、快捷键、画中画、全屏、平台转写字幕、逐句字幕跳转、断点续播与可选的轻度降噪。也可以粘贴本人有权限的 HLS `.m3u8` 地址观看直播。界面采用银灰半透明玻璃、蓝色强调色与系统字体，自动适配系统浅色/深色模式及减少动态效果偏好。默认 16:9 画面铺满右侧可用宽度，顶部操作区采用紧凑布局；非全屏时点击画面或按空格可暂停、继续。播放控件采用官方 Sutro 主题，统一提供进度、音量、倍速、字幕、画中画与全屏；窄窗口中视频与侧栏纵向排列，可在内容区滚动查看。

## 安装

1. 下载并解压本文件夹（若已得到文件夹则无需解压）。
2. Chrome 或 Edge 打开扩展管理页，开启“开发者模式”，选择“加载已解压的扩展程序”，指向本文件夹。
3. 已安装旧版时，在扩展管理页点击扩展的“重新加载”，再刷新已打开的 iCourse 页面。
4. 登录 [iCourse](https://icourse.fudan.edu.cn/)，进入课程页，点击右下角“Lyue”。若课程 ID 未自动识别，把课程页面网址里的数字填入“课程 ID”后点击“打开课程”。

校园内网能直接访问 iCourse 时，直接使用 `icourse.fudan.edu.cn`，无需 WebVPN。若你从 WebVPN 中进入 iCourse，扩展会识别该代理页面，并通过 WebVPN 请求课程与视频。扩展不要求输入或保存 UIS 账号密码。

## 直播

选择正在直播的课次时，扩展从平台的 `/courseapi/v3/portal-home-setting/get-sub-info` 读取 `live_url.output`，优先使用其 HLS 地址，并像平台播放器一样附加 `clientUUID`。若接口返回 `can_watch: false` 或没有直播地址，会显示原因，不会尝试绕过权限。平台状态可能与课表日期不同，以接口返回为准。也可从“连接直播流”粘贴本人有权限的 `.m3u8` 地址。播放器使用 [hls.js](https://github.com/video-dev/hls.js)，并提供“回到直播”按钮。直播服务器若限制跨域请求，浏览器可能无法播放该地址。

## 字幕与声音

- 播放课次时自动读取平台提供的语音转写文本。可用“字幕”按钮或 `C` 键切换视频字幕；侧栏“逐句字幕”可查看文本、点击跳到对应时间。这些文本不是人工校对的字幕，准确度取决于平台识别结果；扩展只负责同步显示。若平台没有提供字幕，会显示“暂无官方字幕”。直播地址不会自动生成字幕。逐句字幕支持关键词搜索与时间跳转，可关闭“跟随播放”自行浏览；字幕读取提示与播放状态分别显示。
- “人声增强”默认关闭。先播放课程，再点击浏览器工具栏中的本扩展图标启动；需要 Chrome／Edge 116+。若图标未显示，先在扩展菜单中固定它。启动后播放器内的“人声增强”按钮切换增强／原声；再次点击工具栏图标会停止捕获。切课、关闭播放器或离开页面时自动停止，重新播放后需按需开启。
- 增强使用温和高通、2.2 kHz 人声频段均衡、动态压缩和固定输出补偿；不是神经网络降噪，不能分离教师与同学或保证消除混响。捕获整个标签页的声音，因此请暂停页面中其他播放器。原生视频音量与静音设置仍控制进入处理链的声音。没有录制、保存或上传音频。
- 0.6.0 新增 `tabCapture`、`offscreen`、`activeTab` 权限及后台音频页面；更新后重新加载扩展并刷新课程页。首次捕获必须由工具栏点击启动，采用 Chrome 官方的后台→离屏页面路径，参见 [官方说明](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture)。

## 实现与数据

- 课程列表沿用参考项目的 `/courseapi/v3/multi-search/get-course-detail`。先按中国时区过滤未来日期的课次；同日标题明确包含开课时刻时按该时刻判断，否则不推测节次时间。尚未开课的课次不显示，也不探测资源。载入后最多并行检查 3 节课的资源，按平台返回的直播或录播地址筛选，找到后逐步显示；确认无地址的课次不显示。网络错误、超时等检查失败单独计数，可点击“重新检查资源”；关闭或切换课程会取消检查。筛选不以 `playback_status` 为硬条件，检查只读取接口元数据，不下载视频；点击播放时重新获取地址并签名。
- 视频沿用参考项目的顺序：先查询 `/courseapi/v3/portal-home-setting/get-sub-info`，依次尝试 `video_list[*].preview_url`、`playurl[*]`、`content.playback.url`；仍没有地址时再查询 `/courseapi/v3/multi-search/get-sub-detail` 的 `content.playback.url`。`get-sub-info` 返回非零代码但附带数据时，仍检查该数据。取得地址后使用 `/userapi/v1/infosimple` 的账户信息生成相同的 `clientUUID`、`t` 参数。
- 直播源发现依据 iCourse 当前网页的播放逻辑：活动课次从 `get-sub-info` 的 `live_url.output` 读取直播地址；不会遍历其他课程或保存带签名的地址。课程状态与可观看权限由平台接口决定。
- 平台转写字幕来自 `/courseapi/v3/web-socket/search-trans-result`，转换为原生字幕轨道，同时供逐句字幕列表使用。
- 本地只保存按课程 ID 与课次区分的播放进度（时间、时长、是否看完）与倍速偏好，兼容旧版数字进度。课次列表显示观看进度；看完后再次点击会从头播放。页面不会持久保存视频、字幕、账号或直播地址；本机 Qwen 服务会另外保存有大小上限的字幕缓存；关闭播放器时视频暂停，并取消待完成的请求。切换课程时停止旧视频，避免进度串入新课程。
- 平台接口请求默认 20 秒超时，失败后可以重新打开课程或选择课次重试。关闭弹窗会恢复背景页面与键盘焦点；Esc 可关闭弹窗，Tab 焦点保持在弹窗内，侧栏标签可用方向键切换。

接口机制参考 [Lucasuiii/Fudan_iCourse_Subscriber](https://github.com/Lucasuiii/Fudan_iCourse_Subscriber/blob/main/src/api/icourse.py)。本扩展不是学校官方产品，请仅播放自己有权限的课程。平台接口若有变化，可能需要更新扩展。

## v1.1.1

采用 [Sutro](https://player.style/themes/sutro) / Media Chrome 官方播放控件，移除重复的手写播放控制。平台、Qwen 与 Whisper 字幕统一同步至原生轨道，CC 开关在后续识别窗口更新时保持用户选择。字幕缓存默认显示一行进度，展开可查看窗口；识别、人声增强与字幕样式收进设置面板，全屏也可使用。

## Git 开发流程

- 在独立的 `feat/…` 或 `fix/…` 分支开发，每次提交围绕一个明确的改动。
- 提交前运行 `node --test tests/core.test.cjs`、`node --check core.js`、`node --check content.js` 和 `git diff --check`。播放器交互、声音或字幕改动还需要相应浏览器验证，并区分模拟结果与真实课程结果。
- 验证通过后明确暂存相关文件并提交。版本变更同步更新 `manifest.json` 与 README，重新生成并核对 ZIP。
- 配置远程仓库后再进行远程同步；同步前检查远程差异，保留本地改动。

## 本地 Whisper 安装

macOS Apple Silicon（其他系统尚未实测）：

```sh
brew install whisper-cpp ffmpeg
python3 local-whisper/install-model.py
sh local-whisper/start-macos.sh
```

模型约 1.6 GB，下载时校验 SHA-256。服务只监听本机 127.0.0.1:8766；在“设置 → 关键词与连接”填写 `~/Library/Application Support/iCourseWhisper/connection-key.txt` 中的密钥，再保存。关键词按课程 ID 保存，可以留空。重启电脑后需再次启动服务；流式识别不需要下载课程视频。

## 播放界面（0.9.1）

播放进度条和控制栏独立放在画面下方。全屏包含同一组控件及字幕层，字幕开关、倍速、音量和退出全屏状态保持同步，不再使用无法控制本地字幕的浏览器原生菜单。Qwen 缓存显示完成窗口数、百分比、当前窗口时间范围、已完成区域，以及音频读取量／识别阶段；识别阶段没有虚构的窗口内百分比。收起侧栏可放大视频。“设置”按组显示字幕来源、关键词、重新识别、人声增强与字幕外观。窄屏自动换行，Escape 先收起设置再关闭播放器。

保存关键词会自动重新连接对应课程的识别。也可点击“重新识别”清空当前逐句列表并重启；它从现在的播放位置继续，若要重做先前的内容，需要回退播放。平台字幕不受关键词影响。

## Whisper 流式字幕（0.9.0 实验功能）

在“设置 → 来源”选择“Whisper 流式”，以 0.75×–2× 播放，再点击浏览器工具栏的Lyue图标授权捕获标签页音频。使用同一个本地 whisper.cpp large-v3-turbo 服务及连接密钥，不需要下载课程视频，录播和直播都可从启用时开始识别。字幕来源仅保留 Whisper 流式与平台字幕。更新后需重新启动本地服务、重新加载扩展并刷新课程页。

音频只发送到本机认证服务，不上传云端，也不写入音频或字幕缓存。约 2 秒音频起步，随着上下文增加更新草稿，停顿或约 12 秒后确认句子（倍速时缩短捕获窗口，最多覆盖约 12 秒原视频内容）并加入逐句字幕；仅允许一个推理请求，音频积压超过 16 秒时跳过过旧音频，只保留最近 4 秒继续识别并提示（跳过部分会有字幕缺口）；切换倍速或点“重新识别”可重启，视频继续播放。暂停、跳转、切换倍速或切课会丢弃未完成句子及迟到结果；0.8.1 起支持 0.75×–2×，字幕时间戳按当次窗口倍速换算；切换倍速丢弃未完成草稿，超过范围暂停识别并提示。捕获整个标签页，请避免其他播放器同时发声。

这是滚动窗口近实时识别，首条字幕需要音频积累和模型推理时间；草稿可能被修正，不能保证逐字零延迟。此机课程样本的 2、4、8、12 秒窗口推理耗时约 2.1–2.6 秒；没有进行完整课堂准确率或真实直播验收。

0.9.1：音频离屏页面直接请求本机 Whisper 服务，避免推理请求通过后台消息转发时无响应；后台仅向扩展自己的音频页面提供连接配置，课程网页收不到密钥。停止识别会取消未完成的本地请求。

0.9.1 实测：已在登录的数值算法课程验证 1×、切换至 1.5× 后出现流式字幕；推理积压恢复改动另由回归测试覆盖。

## Qwen 录播缓存字幕（1.0.0）

已接入未量化 BF16 原版：在“设置 → 来源”选择“Qwen 原版 · 录播缓存”。本机服务通过语音检测、识别和字词对齐生成字幕，按原始音频前瞻约 100 秒，支持 0.75×–2×；切换倍速保留缓存，跳转优先准备新位置，关键词更新后自动重新载入。远程音频直连失败时通过已登录浏览器按 Range 读取索引和当前窗口所需字节，边取边识别，不等待完整视频下载。媒体 RAM 缓存上限 32 MiB，切课或关闭后释放；服务器不支持 Range 时明确报错。安装与启动见 [本地 Qwen](local-qwen/README.md)。平台字幕和 Whisper 流式保留作为备用。

同一 30 分钟授权样本、90 个窗口，以豆包为机器参考：8-bit 一致度 89.15 分，原版 89.23 分；差距很小，不代表原版显著更准，也不是人工准确率。按用户选择保留原版，8-bit 权重已删除。实测一个 24 秒窗口完成语音检测、识别与对齐约 4.28 秒；浏览器模拟检查覆盖倍速、显示和取消，真实课程加载新版后的完整播放尚待验收。见 [测试记录](docs/qwen-window-pilot.md)。

## v1.1.0

Qwen 默认连续缓存整堂录播：当前位置及前方约 100 秒优先，然后依次处理后续窗口，再补齐此前缺失的窗口。即使暂停视频也会继续；关闭播放器、切换来源或课程会停止。设置中的“整课缓存”可关闭长距离预取，保留观看位置附近的缓存。后台采用单窗口串行请求，跳转优先处理新位置；页面仅保留最多 180 个窗口，字幕文件继续保留在本机。

左侧“逐句字幕 → 导出本课字幕”支持 SRT / VTT。平台字幕导出平台提供的内容；Qwen 导出本地已识别的全部窗口，包含已经移出页面内存的部分。未识别完整时文件名带“部分字幕”，缺失部分不会补写或伪装完整；整课缓存完成后再次导出即可。Whisper 导出本次累计的部分字幕。导出不会带上视频地址、连接密钥或音频。

播放界面收起课程输入区、缩短状态栏，常用控制及高级设置放在画面下方。版本号为 Lyue 1.1.0。
