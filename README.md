# Lyue

复旦 iCourse 的 Chrome／Edge 课程播放器扩展。使用已登录的课程页面，提供课次浏览、断点续播、倍速、全屏、逐句字幕、字幕导出和可选人声增强。播放控件采用官方 [Sutro](https://player.style/themes/sutro) 主题。

当前版本以 [manifest.json](manifest.json) 的 `version` 为准；历史变更见 [CHANGELOG](CHANGELOG.md)。

## 安装与更新

需要 Chrome／Edge 116 或更新版本。Safari 不支持此扩展。

1. 下载仓库或安装包并解压，找到包含 `manifest.json` 的 `icourse-player` 文件夹。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择该文件夹。
3. 登录 [iCourse](https://icourse.fudan.edu.cn/)，进入课程页，点击右下角的 **Lyue**。
4. 选择课次开始播放。如果未自动识别课程，展开「切换课程／直播」，填入课程网址中的 `course_id`。

更新时，先在扩展管理页点击 Lyue 的「重新加载」，**再刷新已打开的课程页**。旧页面不会因扩展重新加载而自动替换播放界面。

校园网可直连时使用 iCourse 原站；经 WebVPN 进入时，扩展识别代理页面并转换资源地址。扩展沿用当前登录状态，无需另存 UIS 账号密码。只能观看平台授予当前账号访问权限的课程。

## 播放与快捷键

课次列表支持搜索和观看进度；点击「逐句字幕」可搜索字幕、跳转到对应时间并导出。侧栏可以收起，字幕来源、人声增强和字幕外观位于「识别与增强」设置中。

| 快捷键 | 操作 |
| --- | --- |
| 空格／K | 播放或暂停；全屏及播放控件聚焦时可用 |
| ←／→ | 后退／前进 10 秒 |
| F | 进入或退出全屏 |
| P | 画中画 |
| C | 显示或隐藏字幕 |
| Esc | 优先关闭设置；非全屏时关闭播放器 |

输入框、菜单和滑块保留自身的键盘操作。播放控件聚焦时，其原有快捷键也可能优先处理。

macOS Chrome 全屏仍显示地址栏或标签栏时，在 **View／显示 → Always Show Toolbar in Full Screen／全屏时始终显示工具栏** 中取消勾选。

## 字幕来源

| 来源 | 适用情况 | 所需配置 |
| --- | --- | --- |
| **Qwen 原版缓存** | 录播，打开课次时默认选择 | 启动本机 Qwen 服务并保存连接密钥 |
| 平台字幕 | 平台提供转写文本的课次 | 无需本地识别服务 |
| Whisper 流式 | 录播或直播，实验性近实时识别 | 启动本机 Whisper 服务，并通过 Lyue 工具栏图标启动音频捕获 |

本地 Qwen 安装与启动见 [Qwen 服务说明](local-qwen/README.md)。本地服务只监听回环地址：Qwen 为 `127.0.0.1:8768`，Whisper 为 `127.0.0.1:8766`。在「识别与增强 → 关键词与连接」保存连接密钥；平台字幕可作为不依赖本地服务的备用来源。

Qwen 在视频下方显示当前位置是否已缓存、正在处理的窗口时间段和实际阶段。未缓存的窗口不会显示字幕；已经缓存的窗口在停顿处也可能没有字幕。后续窗口失败时会显示已知原因和恢复操作，并明确标记缓存停止，已完成字幕仍保留。无法连接服务或请求超时不代表已确认服务退出，界面会注明原因未确认。在「识别与增强 → 重新载入」可以重试。

### Whisper 安装（macOS Apple Silicon）

```sh
brew install whisper-cpp ffmpeg
python3 local-whisper/install-model.py
sh local-whisper/start-macos.sh
```

模型约 1.6 GB，下载时校验 SHA-256。连接密钥位于 `~/Library/Application Support/iCourseWhisper/connection-key.txt`。重启电脑后需再次启动服务；流式字幕需要积累音频并完成推理，可能修正草稿或因积压出现缺口。其他系统尚未实测。

### Qwen 缓存与等待

- 优先处理当前位置及前方约 100 秒，再缓存后续窗口，最后补齐此前缺失部分。默认连续缓存整堂录播，暂停视频时仍继续；关闭播放器、切课或切换来源会停止任务。
- 首次等待当前位置字幕默认最多 **5 秒**，超时后恢复原播放状态，后台继续识别，不会因每个缺失窗口反复暂停。可选择不等待、3／5／10／15 秒；手动暂停保持暂停，跳转会开始一次新的限时准备。
- 本机保存字幕窗口缓存，复看时优先复用。缓存键包含媒体路径、模型、关键词和窗口位置；签名链接刷新不改变同一媒体的缓存，关键词修改会使用对应的新缓存，旧结果保留。
- 页面内最多保留 180 个窗口，本机缓存仍可用于导出。缓存未命中时，优先经已登录浏览器使用视频播放地址按 Range 获取当前窗口所需字节；遇到 401／403 会重新获取并签名同一录播地址，最多重试一次。媒体内存缓存上限 32 MiB，不以完整视频下载兜底。

字幕切分优先使用标点与停顿；长句超过显示上限时回找自然边界，并跨相邻识别窗口重新排版。旧缓存的词时间戳可直接复用，无需重新识别。

### 关键词与导出

关键词按课程 ID 保存，最多 800 字。**只使用设置页中保存的内容，不按课程自动追加内置词表**；留空即可使用默认识别。Qwen 和 Whisper 使用同一份关键词，平台字幕不受影响。关键词只是识别参考，不能保证符号或专业术语每次都正确。

在「逐句字幕」选择 SRT／VTT，点击「导出本课字幕」。Qwen 导出本机已完成的窗口；平台来源导出平台提供的文本；Whisper 导出本次累计的文本。尚未识别完整时，文件名标注「部分字幕」，缺失部分不会补写。导出不包含视频地址、连接密钥或音频。

## 人声增强与直播

人声增强默认关闭。先播放课程，再点击浏览器工具栏的 **Lyue 图标**启动捕获；若未显示图标，先在扩展菜单中固定它。播放器设置可切换增强／原声，再次点击工具栏图标会停止捕获。切课、关闭播放器或离开页面时自动停止。

在「识别与增强」中可调节降噪强度（轻度／标准）、自动音量、音色（自然／清晰）及轻度拖尾抑制。默认标准降噪、自动稳定音量、自然音色，拖尾抑制关闭；增强仍需手动启用。设置保存在扩展中，切课后继续沿用。轻度档保留更多原声，也会保留更多噪声；自动音量只在讲话时缓慢调节，最大提升约 6 dB。

增强先使用本地 RNNoise 神经网络抑制空调、风扇等持续背景噪声，再做温和均衡与动态压缩。模型随扩展打包，无需额外服务或下载；加载失败时保留基础增强，并在播放器显示状态。它不支持说话人分离，较弱的人声可能受到影响，可随时切回原声对照。增强只处理回放声音，Qwen 与 Whisper 的识别输入保持原声。拖尾抑制是保守的实验功能，仅压低讲话结束后的部分残留，不能替代完整去混响。新版测量与限制见 [增强检查](docs/audio-1.3.0-check.md)。捕获整个标签页时，请避免其他播放器同时发声。

直播课次优先使用平台返回的 HLS 地址，也可在「连接直播流」粘贴本人有权限的 `.m3u8` 地址。Qwen 缓存仅用于录播；直播可使用平台字幕或 Whisper。直播跨域限制、平台权限和网络状况仍可能影响播放。

## 数据与验证范围

- 页面保存观看进度、倍速及显示偏好；扩展保存本地服务密钥和课程关键词。本机 Qwen 服务另存字幕缓存，不保存 UIS 密码，也不将识别音频上传云端。
- 关闭播放器会暂停视频并取消待完成的请求。课程资源通过平台接口查询，地址按需签名，直连与 WebVPN 路径分别处理；实现参考 [Fudan_iCourse_Subscriber](https://github.com/Lucasuiii/Fudan_iCourse_Subscriber/blob/main/src/api/icourse.py)。
- 已在授权课程页验证基本播放、2×、CC、全屏及部分本地字幕流程。模拟接口、合成音频和机器参考评分不代表所有课程、真实直播或完整课堂准确率通过验收。详细记录见 [Qwen 测试](docs/qwen-window-pilot.md) 和 [音频路线](docs/audio-roadmap.md)。

## 开发

安装扩展无需 Node.js。开发时在本文件夹执行：

```sh
npm ci --ignore-scripts
npm run build:player
npm run build:audio
npm test
python3 -m unittest discover -s local-qwen -p 'test_*.py'
python3 -m unittest discover -s local-whisper -p 'test_*.py'
git diff --check
```

组件打包在扩展内，不从 CDN 加载。只有公开播放 UI 运行于 MAIN 世界；识别、密钥和扩展通信保留在隔离环境。版本只修改 `manifest.json` 中的 `version`，播放器自动读取它；更新时同步 CHANGELOG 并重新生成安装包。播放器、字幕或声音改动还需相应的浏览器验证。
