# iCourse 随行播放器

在已经登录的复旦 iCourse 页面中观看课程。支持课次列表、搜索、自动发现直播源、倍速、快捷键、画中画、全屏、平台转写字幕、逐句字幕跳转、断点续播与可选的轻度降噪。也可以粘贴本人有权限的 HLS `.m3u8` 地址观看直播。界面采用银灰半透明玻璃、蓝色强调色与系统字体，自动适配系统浅色/深色模式及减少动态效果偏好。默认 16:9 画面铺满右侧可用宽度，顶部操作区采用紧凑布局；非全屏时点击画面或按空格可暂停、继续。屏幕高度不足时可在播放器右侧向下滚动查看画面下方的控制按钮；窄窗口中视频与侧栏纵向排列，可在内容区滚动查看。

## 安装

1. 下载并解压本文件夹（若已得到文件夹则无需解压）。
2. Chrome 或 Edge 打开扩展管理页，开启“开发者模式”，选择“加载已解压的扩展程序”，指向本文件夹。
3. 已安装旧版时，在扩展管理页点击扩展的“重新加载”，再刷新已打开的 iCourse 页面。
4. 登录 [iCourse](https://icourse.fudan.edu.cn/)，进入课程页，点击右下角“随行播放器”。若课程 ID 未自动识别，把课程页面网址里的数字填入“课程 ID”后点击“打开课程”。

校园内网能直接访问 iCourse 时，直接使用 `icourse.fudan.edu.cn`，无需 WebVPN。若你从 WebVPN 中进入 iCourse，扩展会识别该代理页面，并通过 WebVPN 请求课程与视频。扩展不要求输入或保存 UIS 账号密码。

## 直播

选择正在直播的课次时，扩展从平台的 `/courseapi/v3/portal-home-setting/get-sub-info` 读取 `live_url.output`，优先使用其 HLS 地址，并像平台播放器一样附加 `clientUUID`。若接口返回 `can_watch: false` 或没有直播地址，会显示原因，不会尝试绕过权限。平台状态可能与课表日期不同，以接口返回为准。也可从“连接直播流”粘贴本人有权限的 `.m3u8` 地址。播放器使用 [hls.js](https://github.com/video-dev/hls.js)，并提供“回到直播”按钮。直播服务器若限制跨域请求，浏览器可能无法播放该地址。

## 字幕与声音

- 播放课次时自动读取平台提供的语音转写文本。可用“字幕”按钮或 `C` 键切换视频字幕；侧栏“逐句字幕”可查看文本、点击跳到对应时间。这些文本不是人工校对的字幕，准确度取决于平台识别结果；扩展只负责同步显示。若平台没有提供字幕，会显示“暂无官方字幕”。直播地址不会自动生成字幕。逐句字幕支持关键词搜索与时间跳转，可关闭“跟随播放”自行浏览；字幕读取提示与播放状态分别显示。
- “人声增强”默认关闭。先播放课程，再点击浏览器工具栏中的本扩展图标启动；需要 Chrome／Edge 116+。若图标未显示，先在扩展菜单中固定它。启动后播放器内的“人声增强”按钮切换增强／原声；再次点击工具栏图标会停止捕获。切课、关闭播放器或离开页面时自动停止，重新播放后需按需开启。
- 增强使用温和高通、2.2 kHz 人声频段均衡、动态压缩和固定输出补偿；不是神经网络降噪，不能分离教师与同学或保证消除混响。捕获整个标签页的声音，因此请暂停页面中其他播放器。原生视频音量与静音设置仍控制进入处理链的声音。没有录制、保存或上传音频。
- 0.6.0 新增 `tabCapture`、`offscreen`、`activeTab` 权限及后台音频页面；更新后重新加载扩展并刷新课程页。首次捕获必须由工具栏点击启动，采用 Chrome 官方的后台→离屏页面路径，参见 [官方说明](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture)。

## 实现与数据

- 课程列表沿用参考项目的 `/courseapi/v3/multi-search/get-course-detail`。先按中国时区过滤未来日期的课次；同日标题明确包含开课时刻时按该时刻判断，否则不推测节次时间。尚未开课的课次不显示，也不探测资源。载入后最多并行检查 3 节课的资源，按平台返回的直播或录播地址筛选，找到后逐步显示；确认无地址的课次不显示。网络错误、超时等检查失败单独计数，可点击“重新检查资源”；关闭或切换课程会取消检查。筛选不以 `playback_status` 为硬条件，检查只读取接口元数据，不下载视频；点击播放时重新获取地址并签名。
- 视频沿用参考项目的顺序：先查询 `/courseapi/v3/portal-home-setting/get-sub-info`，依次尝试 `video_list[*].preview_url`、`playurl[*]`、`content.playback.url`；仍没有地址时再查询 `/courseapi/v3/multi-search/get-sub-detail` 的 `content.playback.url`。`get-sub-info` 返回非零代码但附带数据时，仍检查该数据。取得地址后使用 `/userapi/v1/infosimple` 的账户信息生成相同的 `clientUUID`、`t` 参数。
- 直播源发现依据 iCourse 当前网页的播放逻辑：活动课次从 `get-sub-info` 的 `live_url.output` 读取直播地址；不会遍历其他课程或保存带签名的地址。课程状态与可观看权限由平台接口决定。
- 平台转写字幕来自 `/courseapi/v3/web-socket/search-trans-result`，在页面内生成 WebVTT，同时供逐句字幕列表使用。
- 本地只保存按课程 ID 与课次区分的播放进度（时间、时长、是否看完）与倍速偏好，兼容旧版数字进度。课次列表显示观看进度；看完后再次点击会从头播放。视频、字幕、账号和直播地址不会被持久保存；关闭播放器时视频暂停，并取消待完成的请求。切换课程时停止旧视频，避免进度串入新课程。
- 平台接口请求默认 20 秒超时，失败后可以重新打开课程或选择课次重试。关闭弹窗会恢复背景页面与键盘焦点；Esc 可关闭弹窗，Tab 焦点保持在弹窗内，侧栏标签可用方向键切换。

接口机制参考 [Lucasuiii/Fudan_iCourse_Subscriber](https://github.com/Lucasuiii/Fudan_iCourse_Subscriber/blob/main/src/api/icourse.py)。本扩展不是学校官方产品，请仅播放自己有权限的课程。平台接口若有变化，可能需要更新扩展。

## 开发验证

在本文件夹执行 `node --test tests/core.test.cjs`，检查接口超时、取消、部分响应回退、直连/WebVPN 与地址签名。前端修改另经本地模拟接口和媒体事件的浏览器检查；模拟检查不代表真实课程、直播跨域或视频解码已经验证。

## Git 开发流程

- 在独立的 `feat/…` 或 `fix/…` 分支开发，每次提交围绕一个明确的改动。
- 提交前运行 `node --test tests/core.test.cjs`、`node --check core.js`、`node --check content.js` 和 `git diff --check`。播放器交互、声音或字幕改动还需要相应浏览器验证，并区分模拟结果与真实课程结果。
- 验证通过后明确暂存相关文件并提交。版本变更同步更新 `manifest.json` 与 README，重新生成并核对 ZIP。
- 配置远程仓库后再进行远程同步；同步前检查远程差异，保留本地改动。

## 人声增强验证范围（0.5.0）

21 项 Node 测试覆盖课程查询与音频生命周期、隔离、错误恢复；真实浏览器 OfflineAudioContext 检查了原声通路、低频衰减、人声频段和测试音峰值。页面按钮及切课／关闭使用模拟扩展消息回归。真实工具栏授权→tabCapture→离屏回放的完整链路以及实际课堂听感尚未实测，不把模拟消息测试作为这些环节的通过证据。

## 本地流式字幕（0.6.0 实验功能）

1. 完整试用 ZIP 已含模型。Git 克隆的源码需先在项目目录运行 `python3 scripts/install-asr.py`，下载约 182 MB 官方包，并校验 SHA-256；解压模型约 199 MB、WASM 约 12 MB。不下载课程录音。
2. 重新加载扩展、刷新课程页并播放课程；将“来源”切换为“本地识别（实验）”，再点击工具栏中的本扩展图标启动音频捕获。已有捕获时切换来源即可加载模型。
3. 当前仅支持 1×；倍速时识别暂停并提示切回原速。需要纯原声时，将“人声增强”关闭，识别仍从原始捕获分支运行。
4. 视频内显示实时草稿，断句后加入逐句字幕。可切回平台字幕；本地字幕仅积累启用后的片段，最多保留 500 句，不写入磁盘。拖动、暂停等播放边界清除识别流的未完成结果；切课清空本地历史并恢复平台来源。

模型与代码均从本地扩展资源加载，课程音频不上传。模型在 Worker 中运行，PCM 来自独立 AudioWorklet；排队超过约半秒会停止识别、提示原因，音频回放继续。时间为播放时钟近似映射，尚未做词级强制对齐；标签页其他声音也会进入识别，原生静音／音量可能影响识别。自定义本地字幕浮层支持页面全屏，画中画窗口中不显示。

验证：26 项 Node 测试通过；真实浏览器使用本机 Tingting 合成的中文测试语音，验证了 WASM 加载、连续草稿、断句与 16/48 kHz 输入。约 7.8 秒合成语音的解码耗时约 1.1 秒（16 kHz 首次测试），不包含模型加载，也不代表实际课堂的准确率或延迟。“二叉树”出现错字。真实 AudioWorklet→Worker 的 48 kHz 连续输入也已跑通。页面来源切换／拖动回归使用模拟扩展消息；真实工具栏→课程音轨→字幕的完整链路尚未端到端实测。

更新排查（0.6.1）：只刷新课程页面不会重新加载扩展后台。若人声增强可用但本地识别提示后台不支持或没有响应，请在 Chrome / Edge 扩展管理页重新加载随行播放器，然后刷新课程页面，再以 1× 播放、选择本地识别并点击工具栏图标。0.6.1 增加了后台能力检查；模型加载或识别错误仍会显示其具体原因。

## Whisper 录播预取（0.7.0 实验功能）

该模式使用本机 `whisper.cpp` + `large-v3-turbo` + Silero VAD。先识别当前播放位置，每段 20 秒并带两侧上下文，继续准备后面约 100 秒；识别结果按原录播时间显示并缓存到本机。首次准备或拖到未缓存区域时暂停，当前位置字幕就绪后自动恢复；可点击“取消等待”切回平台字幕。已识别字幕支持倍速；直播暂不支持，页面全屏可显示，画中画中不显示自定义字幕。

macOS Apple Silicon 安装（其他系统尚未实测）：

```sh
brew install whisper-cpp ffmpeg
python3 local-whisper/install-model.py
sh local-whisper/start-macos.sh
```

模型约 1.6 GB，安装脚本从官方仓库的固定版本下载并校验 SHA-256。服务只监听 `127.0.0.1`；启动后打开播放器的“Whisper 设置”，填写 `~/Library/Application Support/iCourseWhisper/connection-key.txt` 中的密钥，再检查连接。默认不加课程术语预设，可直接识别音频；按需填写课程 ID 与术语时只影响指定课程，两者均选填。然后选择来源“Whisper 预取（实验）”。服务需保持运行；重启电脑后再次执行启动命令。修改 `ICOURSE_WHISPER_HOME` 可指定模型、缓存及导入录播的保存目录。

服务尝试直接读取已签名的 MP4 地址。如果平台要求浏览器登录而返回 403，可在视频原生菜单下载**本人有权限且已获授权**的录播，将保持原始文件名的 MP4 放入 `~/Library/Application Support/iCourseWhisper/media/`，再点“重新准备字幕”。它只匹配明确配置的这个目录；不读取或复制浏览器 Cookie。下载文件名改变或使用裁切音频时，可以注册：

```sh
python3 local-whisper/register-recording.py --url-file /path/to/video-url.txt \
  --file /path/to/authorized-recording.mp4
# 裁切从原视频第 600 秒开始的片段时，额外加 --offset 600
```

`video-url.txt` 为当前视频地址的本地文本，仅用于匹配录播；不要公开含签名的 URL。注册只保存录播身份摘要、文件名与起始秒数，复制媒体到本地服务目录；超出裁切片段覆盖范围时明确提示，不生成空字幕缓存。若只保存 WAV 音频，可用同一注册命令。

音频仅在本机提取、推理；连接密钥只存于扩展存储。后台权限仅增加扩展存储及固定本机端口，不接入云端识别。字幕缓存包含课堂文本，最多 1800 段（约 10 小时），可在服务停止后删除本地 `cache/` 目录清空；导入的录播不会自动删除。不同模型和处理版本的缓存分开。切课、关闭播放器会丢弃过期回复；已开始的推理可能继续完成并写入本地缓存。

课堂停顿、混响、英文人名与公式仍可能错识别；VAD、解码回退及明显重复过滤用于减少无声片段的重复输出，不能保证人工字幕质量。不要将字幕当作准确的数学公式记录。
