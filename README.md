# iCourse 随行播放器

在已经登录的复旦 iCourse 页面中观看课程。支持课次列表、搜索、自动发现直播源、倍速、快捷键、画中画、全屏、平台转写字幕、逐句字幕跳转、断点续播与可选的轻度降噪。也可以粘贴本人有权限的 HLS `.m3u8` 地址观看直播。界面采用银灰半透明玻璃、蓝色强调色与系统字体，自动适配系统浅色/深色模式及减少动态效果偏好。默认 16:9 画面铺满右侧可用宽度，顶部操作区采用紧凑布局；非全屏时点击画面或按空格可暂停、继续。屏幕高度不足时可在播放器右侧向下滚动查看画面下方的控制按钮；窄窗口中视频与侧栏纵向排列，可在内容区滚动查看。

## 安装

1. 下载并解压本文件夹（若已得到文件夹则无需解压）。
2. Chrome 或 Edge 打开扩展管理页，开启“开发者模式”，选择“加载已解压的扩展程序”，指向本文件夹。
3. 已安装旧版时，在扩展管理页点击扩展的“重新加载”，再刷新已打开的 iCourse 页面。
4. 登录 [iCourse](https://icourse.fudan.edu.cn/)，进入课程页，点击右下角“随行播放器”。若课程 ID 未自动识别，把课程页面网址里的数字填入“课程 ID”后点击“打开课程”。

校园内网能直接访问 iCourse 时，直接使用 `icourse.fudan.edu.cn`，无需 WebVPN。若你从 WebVPN 中进入 iCourse，扩展会识别该代理页面，并通过 WebVPN 请求课程与视频。扩展不要求输入或保存 UIS 账号密码。

## 直播

选择正在直播的课次时，扩展从平台的 `/courseapi/v3/portal-home-setting/get-sub-info` 读取 `live_url.output`，优先使用其 HLS 地址，并像平台播放器一样附加 `clientUUID`。若接口返回 `can_watch: false` 或没有直播地址，会显示原因，不会尝试绕过权限。平台状态可能与课表日期不同，以接口返回为准。也可从“连接直播流”粘贴本人有权限的 `.m3u8` 地址。播放器使用 [hls.js](https://github.com/video-dev/hls.js)，并提供“回到直播”按钮。直播服务器若限制跨域请求，浏览器可能无法播放该地址。

## 字幕与声音

- 播放课次时自动读取平台提供的语音转写文本。可用“字幕”按钮或 `C` 键切换视频字幕；侧栏“逐句字幕”可查看文本、点击跳到对应时间。这些文本不是人工校对的字幕，准确度取决于平台识别结果；扩展只负责同步显示。若平台没有提供字幕，会显示“暂无官方字幕”。直播地址不会自动生成字幕。逐句字幕支持关键词搜索与时间跳转，可关闭“跟随播放”自行浏览；字幕读取提示与播放状态分别显示。
- “轻度降噪”默认关闭，只过滤人声以外的低频轰鸣和高频底噪。它不是 AI 语音修复，不能消除与讲话同时出现的杂音。浏览器不能安全处理跨域音频时会保持原声，并提示不可用；切换课次后需按需重新开启。

## 实现与数据

- 课程列表沿用参考项目的 `/courseapi/v3/multi-search/get-course-detail`。先按中国时区过滤未来日期的课次；同日标题明确包含开课时刻时按该时刻判断，否则不推测节次时间。尚未开课的课次不显示，也不探测资源。载入后最多并行检查 3 节课的资源，按平台返回的直播或录播地址筛选，找到后逐步显示；确认无地址的课次不显示。网络错误、超时等检查失败单独计数，可点击“重新检查资源”；关闭或切换课程会取消检查。筛选不以 `playback_status` 为硬条件，检查只读取接口元数据，不下载视频；点击播放时重新获取地址并签名。
- 视频沿用参考项目的顺序：先查询 `/courseapi/v3/portal-home-setting/get-sub-info`，依次尝试 `video_list[*].preview_url`、`playurl[*]`、`content.playback.url`；仍没有地址时再查询 `/courseapi/v3/multi-search/get-sub-detail` 的 `content.playback.url`。`get-sub-info` 返回非零代码但附带数据时，仍检查该数据。取得地址后使用 `/userapi/v1/infosimple` 的账户信息生成相同的 `clientUUID`、`t` 参数。
- 直播源发现依据 iCourse 当前网页的播放逻辑：活动课次从 `get-sub-info` 的 `live_url.output` 读取直播地址；不会遍历其他课程或保存带签名的地址。课程状态与可观看权限由平台接口决定。
- 平台转写字幕来自 `/courseapi/v3/web-socket/search-trans-result`，在页面内生成 WebVTT，同时供逐句字幕列表使用。
- 本地只保存按课程 ID 与课次区分的播放进度（时间、时长、是否看完）与倍速偏好，兼容旧版数字进度。课次列表显示观看进度；看完后再次点击会从头播放。视频、字幕、账号和直播地址不会被持久保存；关闭播放器时视频暂停，并取消待完成的请求。切换课程时停止旧视频，避免进度串入新课程。
- 平台接口请求默认 20 秒超时，失败后可以重新打开课程或选择课次重试。关闭弹窗会恢复背景页面与键盘焦点；Esc 可关闭弹窗，Tab 焦点保持在弹窗内，侧栏标签可用方向键切换。

接口机制参考 [Lucasuiii/Fudan_iCourse_Subscriber](https://github.com/Lucasuiii/Fudan_iCourse_Subscriber/blob/main/src/api/icourse.py)。本扩展不是学校官方产品，请仅播放自己有权限的课程。平台接口若有变化，可能需要更新扩展。

## 开发验证

在本文件夹执行 `node --test tests/core.test.cjs`，检查接口超时、取消、部分响应回退、直连/WebVPN 与地址签名。前端修改另经本地模拟接口和媒体事件的浏览器检查；模拟检查不代表真实课程、直播跨域或视频解码已经验证。

## Git 开发流程

- 在独立的 `feat/…` 或 `fix/…` 分支开发，每次提交围绕一个明确的改动。
- 提交前运行 `node --test tests/core.test.cjs`、`node --check core.js`、`node --check content.js` 和 `git diff --check`。播放器交互、声音或字幕改动还需要相应浏览器验证，并区分模拟结果与真实课程结果。
- 验证通过后明确暂存相关文件并提交。版本变更同步更新 `manifest.json` 与 README，重新生成并核对 ZIP。
- 配置远程仓库后再进行远程同步；同步前检查远程差异，保留本地改动。
