# Lyue 1.1.4 音频与课程词表检查

## 改动与限制

增强链为 85 Hz 高通 → 50 Hz 窄带陷波（Q=12）→ 250 Hz / -2 dB 均衡 → 2.2 kHz / +2.5 dB 人声均衡 → 7.5 kHz 低通 → 动态压缩。压缩阈值 -18 dB、膝宽 12 dB、比例 1.5:1、attack 10 ms、release 180 ms。依据 Web Audio 的固定补偿增益定义，以 `10^(0.6 * threshold * (1 - 1/ratio) / 20)` 抵消全幅区补偿增益，避免把小信号和安静噪声一起固定放大。

参考：[Web Audio 固定补偿增益](https://www.w3.org/TR/webaudio-1.0/#DynamicsCompressorNode-processing)。这是滤波与轻度动态处理，不是神经网络降噪。它不能分离教师与学生声音或消除教室混响；50 Hz 陷波不代表对附近频率或整个噪声频带有相同抑制。识别音频仍来自原声，不宣称提高了 ASR 准确率。

课程 38146 的上下文在扩展后台附加，包含希腊字母及数值算法词表；Qwen inference/cache/export 与 Whisper 使用同一份提示，自定义词优先，总长度 800 字。Qwen 原版模型的 context 能提供上下文，但不等同于强制输出或文本替换，参见 [Qwen3-ASR 官方实现](https://github.com/QwenLM/Qwen3-ASR)。旧缓存按旧提示保留，新的提示使用独立缓存键。

## Chrome OfflineAudioContext 测量

日期：2026-10-03；对照基线 `169aeb7` 的 voice.js。采样率 48 kHz，单声道，每次 2 秒，只测最后 1 秒排除切换与滤波过渡。低电平输入为振幅 0.05 的正弦，比较新旧增强链和原声。数值为 RMS 相对原声的 dB；测试数据不是课堂信号。

50 Hz 精确中心的稳态陷波深度超过测量的实用范围，仅作为中心频率被抑制的功能检查，不推广为实际噪声降幅。100–4000 Hz 样点及 8 kHz 样点没有明显失声；这不等于完整人声频谱或课堂听感验收。原声 RMS 最大误差小于 1e-8；2.2 kHz、振幅 0.9 的测试音输出峰值 0.6464，未削波。
