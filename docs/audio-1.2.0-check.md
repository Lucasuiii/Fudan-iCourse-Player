# Lyue 1.2.0 持续背景降噪检查

日期：2026-10-03。目标是空调、风扇等持续背景噪声。

## 实现

- 使用 `@jitsi/rnnoise-wasm@0.2.1` 的同步 RNNoise 0.2 模型，随扩展打包为本地 AudioWorklet，不下载模型、不上传回放音频。
- 捕获音频由浏览器转换为 48 kHz；两个独立 RNNoise 状态处理左右声道，每帧 480 样本，在 128 样本的浏览器音频块间保持连续缓冲。单声道复制到两个输出声道。
- 之后沿用高通、50 Hz 陷波、轻度均衡、低通与动态压缩；保留原声旁路。压缩器固定补偿维持此前行为。
- Qwen 仍从课程资源识别；Whisper 仍连接捕获源的原声分支，降噪切换不改变识别音频或字幕缓存。
- 加载有 5 秒上限，期间基础增强已输出声音；加载失败或处理器出错回退基础增强。处理器出错时同步更新播放器状态。停止捕获时释放 WASM 状态与内存、关闭音频上下文。

## 验证与边界

Chrome 本地测试页使用真实 AudioWorklet/WASM，以固定种子的低通随机噪声加 120 Hz 嗡声模拟持续背景噪声；另使用 macOS Tingting 合成中文语音，前后各留 2 秒噪声。录音、麦克风及真实课程音频均未用于此测量。

| 项目 | 结果 |
| --- | --- |
| 真实 Chrome 模型初始化 | 80 ms，模式为 RNNoise |
| 纯合成噪声稳态衰减 | 84.25 dB（仅此简单测试信号） |
| 合成人声混噪片段整体 RMS 变化 | −0.33 dB |
| 输出有限值、原声／增强切换 | 通过 |
| 上下文停止清理 | closed |

纯噪声结果不代表实际课堂可达到同等抑制；片段 RMS 接近不证明人声清晰度或准确保留。真实课程音色、较远或较弱的人声、混响与瞬态噪声仍需试听；RNNoise 不提供说话人分离。处理存在帧缓冲与模型延迟，切换时通过增益渐变减轻突变。

自动测试实际运行打包后的 WASM，并验证持续噪声至少衰减 6 dB、左右声道独立、单声道输出一致、帧跨块连续、资源释放，以及加载失败、初始化超时、关闭中的晚到回调不会重新连接音频。音频图测试验证识别原声连接在成功接入及运行失败回退时均保留。
