# Lyue 1.3.0 人声增强检查

日期：2026-10-03。先加入强度控制与音量稳定，再加入音色控制和实验拖尾抑制。

## 信号链与参数

捕获源 → RNNoise/强度混合/音量稳定/拖尾抑制 → 高通/50 Hz 陷波/均衡/低通 → 温和压缩 → 增益补偿 → 软峰值保护 → 输出。原声旁路及 Whisper 原声分支独立，Qwen 使用原始媒体，与增强设置无关。

- **强度**：标准为 RNNoise 输出，轻度为 80% RNNoise + 20% 原声；混合在工作线程逐样本平滑。使用本机合成中文语音测得当前 RNNoise 0.2 输出加帧缓冲延迟为 1440 样本（48 kHz 下 30 ms），原声按同样延迟混合。模型升级需重新测量，不将此值视为所有模型的通用延迟。
- **音量**：由 RNNoise 语音概率 ≥0.6 且降噪后 RMS >0.008 的帧估计目标 RMS 0.08，增益限制 0.5～2（约 ±6 dB）。下降时间常数 0.2 秒，上升 1.5 秒；静音与低语音概率帧不提高增益。左右声道共用增益，避免声像偏移。这是受限的 RMS 调节，不是 LUFS 标准响度归一化。很轻的讲话低于门限时也不放大。
- **自然音色**：高通 65 Hz、250 Hz −0.5 dB、2.2 kHz 0 dB、低通 16 kHz。
- **清晰音色**：沿用 85 Hz、250 Hz −2 dB、2.2 kHz +2.5 dB、低通 7.5 kHz。两种音色都保留 50 Hz 陷波与轻度压缩，参数切换平滑。未加入自动音色分类。
- **峰值**：增强输出末端采用软饱和曲线，0.85 以下近似直通，高于阈值渐进限制，曲线极大输入限制到约 0.94；浏览器重采样存在小幅过冲，极大输入测试输出峰值约 0.954。原声旁路不受处理。
- **拖尾**：默认关闭。曾检测到讲话后，保留至少 120 ms，只有语音概率 <0.2 时渐进降低到 60%，再次讲话快速恢复。它是残留尾音衰减，不能分离早期反射、重建干声或替代完整去混响；可能削弱误判为非语音的弱尾音。

默认：标准、自动音量开启、自然音色、拖尾关闭。启用捕获仍需点击工具栏。偏好由扩展保存；正在使用捕获的另一标签页不能修改。工作线程失败会恢复基础音色增强，自动音量与拖尾不可用。

## 验证

- 单元与实际 WASM 测试：强度与 1440 样本对齐、静音不增益、弱语音渐进提升且有上限、长时间不同音量语音差异缩小、左右增益一致、功能关闭平滑恢复、拖尾保持/衰减/恢复、音频旁路与识别连接、失败回退、设置保存与跨标签页隔离。
- 本地浏览器实际 AudioWorklet/音频图：模型加载、四项切换、原声切换、资源关闭；合成中文语音与人工混响/持续噪声的各模式输出均为有限值。轻度混合与理论延迟对齐结果最大误差约 1.49e-8。
- 人工拖尾片段实验中额外衰减仅约 0.33 dB，效果较小；这不是客观语音质量或真实课堂去混响验证。
- 播放器模拟页面验证四项选择、保存提示；后台保存及正在捕获时应用另有运行测试。

未验证所有真实课程的主观音色、弱语音保留或嘈杂教室效果。合成 RMS 与增益测试不能替代试听；所有选项可关闭并与原声对照。算法保持本地执行，无新增网络请求或权限。
