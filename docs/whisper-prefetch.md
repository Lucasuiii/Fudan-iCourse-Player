# Whisper 录播预取的边界与验证

扩展内容脚本只调度时间段、显示字幕；背景脚本从扩展存储读连接密钥，固定向 `127.0.0.1:8766` 发请求。Python 服务校验令牌、Host、Origin、平台域名、录播类型及时间范围，再通过 FFmpeg 提取单声道 16 kHz PCM，调用常驻 whisper.cpp 引擎。模型为官方 large-v3-turbo，配合 Silero VAD、beam search 和解码回退；明显重复输出被过滤，不替换为猜测的文本。每段带前后两秒上下文，输出按原始录播时钟裁定所属段。

当前范围：MP4 录播、20 秒分段、当前位置优先、约 100 秒前瞻；服务每次只推理一段。字幕缓存以录播路径、模型 SHA-256、固定解码配置、时间段及处理版本索引，签名刷新不使缓存失效。单页最多保存 180 段，本机磁盘最多保存 1800 段。切课或停止后忽略旧回复；已经运行的任务可能继续完成。首次准备或跳到未缓存位置时短暂停播，可取消等待。推理失败会显示原因并恢复先前正在播放的视频。

实际遇到的平台限制：浏览器能播放不代表 FFmpeg 能独立下载；需要浏览器登录时会返回 403。本实现不复制 Cookie、不绕过权限。可导入已获授权下载的录播或裁切片段。文件匹配只读取显式指定的本地目录；注册文件使用媒体身份摘要，拒绝路径逃逸和目录外符号链接。裁切片段使用原视频起点对齐，片段覆盖不足时不会写入成功缓存。

## 本次验证（2026-09-30）

- 38 项 Node 单元测试、8 项 Python 单元测试通过，覆盖消息隔离、认证、资源调度、过期回复、拖动优先级、缓存身份、本地文件范围及重复输出过滤。
- 独立浏览器中使用模拟媒体/扩展消息检查了 10 个预取交互，包括暂停准备、恢复播放、2×、跳转、取消等待、关闭重开、逐句字幕；旧轻量 ASR 的 8 个交互回归也通过。模拟消息检查不证明真实 Chrome 扩展消息链路。
- 在本机 Apple Silicon、16 GB 内存环境中，用已获授权的真实课堂音频裁切 30 分钟，whisper.cpp 1.9.4 + large-v3-turbo + Silero VAD 处理约 208 秒，RTF 约 0.116。该长音频结果衡量吞吐，不代表首次加载耗时或每段识别延迟。
- 常驻服务对 6 个真实 20 秒片段识别约 2.7–3.5 秒（含本地音频提取），回访缓存不再推理。首次模型启动、远程下载、其他 GPU 负载会改变时间；未测其他电脑。
- 无 VAD 且关闭解码回退时曾在课堂停顿处输出大量重复术语；恢复回退、启用 VAD 后，这些测试位置改为有意义的讲解。数学术语和英文人名仍存在错字。没有人工逐字标注，因此不报告准确率，也不宣称达到人工字幕质量。

真实 Chrome 课程页已完成密钥保存与连接检查，Whisper 字幕、逐句列表和约 84 秒预取已显示；测试使用导入的本地课堂音频与浏览器中的原始录播。该结果不代表其他未导入课次可以绕过平台 403 直接取流。

课堂媒体、签名 URL、文本、连接密钥均未提交仓库。服务安装与导入步骤见 README；常驻服务需要用户自行启动，未添加开机启动项。
