# Qwen 浏览器取流与字幕切分检查

2026-10-03，Lyue 1.2.1。

## 取流

字幕窗口先查询现有本地缓存。缓存未命中时使用播放器当前地址，经浏览器携带登录 Cookie 按 Range 读取所需字节，再交给本地 Qwen 解码识别；不再先尝试缺少浏览器登录状态的本地远程取流。

遇到 401／403，重新查询当前课次与账户信息，使用平台时间签名原始视频路径，再转换 WebVPN 地址；已经被 WebVPN 转换的地址也按上游路径签名。一个识别窗口最多刷新重试一次；后续窗口复用刷新后的取流地址，避免每个窗口重复访问过期链接。刷新后的媒体 origin/path 必须与原媒体一致，否则停止并提示重新选择课次。刷新只更新取流地址，缓存仍使用原媒体标识；不修改 video.src、播放位置、倍速或关键词。

现有 32 MiB 上限、精确分段验证、禁止完整响应兜底、切课取消与临时会话清理保持有效。浏览器分段读取仍可能受真实平台权限、登录过期或跨域策略限制；持续拒绝不会无限重试。

## 字幕切分

页面跨相邻窗口重新排版 owned words；后端从旧缓存的词时间戳重新生成字幕，不修改缓存键或重跑识别。超过 36 字或 8 秒的显示上限时，优先回找合适的逗号、停顿或转折处，缺少自然边界时仍采用安全长度限制；完整对齐词不拆开。句末闭引号与标点保持在前句，单字符英文/数字片段不插入多余空格，完整英文词之间保留空格。

这是基于标点与时间戳的可读性改进，未加入语言模型重写或中文分词模型；缺少停顿的长句、错误识别或错误对齐仍可能切分不自然。单个原始对齐词超过长度上限时保留完整词。

## 验证

- Node 测试覆盖浏览器优先、缓存命中不取流、一次 403 刷新、持续 403 有界失败、取消、资源变化、WebVPN 签名与平台时间。
- Python 测试覆盖刷新签名继续复用旧缓存、原有分段解码，并和页面共用切分案例，检查文字、标点及时间戳。
- 真实 Chrome 的本地模拟课程验证：视频与分段请求携带同一 Cookie；初始音频探测 403，刷新一次后 206，后续 Range 使用新地址；页面切分案例通过。

本地模拟验证不代表所有真实课程的 403 已消除。更新扩展后需要在实际课程页确认；后端代码更新需重启本地 Qwen 服务生效。
